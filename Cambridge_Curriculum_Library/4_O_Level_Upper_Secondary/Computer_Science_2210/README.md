# Computer Science — 4_O_Level_Upper_Secondary

> Theory of computation, programming, data representation, computer architecture, networks, and security.

**Syllabus code:** `2210`  
**Age range:** 14–16  
**Prerequisites:** Basic digital literacy; no prior programming assumed.

- [`Mark_Schemes/`](./Mark_Schemes/) — index of mark schemes & examiner reports

## Key Topics
1. Data representation (binary, hex, ASCII, Unicode)
1. Data transmission and compression
1. Algorithms, flowcharts, pseudocode
1. Programming concepts (variables, loops, conditionals, arrays)
1. Logic gates and Boolean algebra
1. Computer architecture (CPU, memory, I/O)
1. Operating systems and software
1. Networks and the internet
1. Cyber security and ethics
