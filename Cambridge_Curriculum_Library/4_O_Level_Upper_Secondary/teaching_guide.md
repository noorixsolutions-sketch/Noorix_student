# Teaching Guide — 4 O Level Upper Secondary

Cambridge O Level for ages 14–16. Internationally recognised qualification with a strong academic track; sits alongside IGCSE.

## Pedagogical Approach

### For ages 14–16

- Use **active learning** strategies — students learn by doing.
- Incorporate **formative assessment** in every lesson.
- Build **cross-curricular connections** where possible.
- Differentiate for **varied learning needs**.

## Recommended Teaching Strategies

| Strategy | When to Use |
| --- | --- |
| Direct instruction | Introducing new concepts |
| Guided discovery | Developing understanding |
| Collaborative learning | Applying and analysing |
| Independent study | Revision and consolidation |

## Assessment Framework

- **Formative:** Quizzes, exit tickets, peer assessment, class discussions
- **Summative:** End-of-topic tests, mock examinations, final exams
