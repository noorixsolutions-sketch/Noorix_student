# English Second Language — 5_IGCSE_Upper_Secondary

> English for learners whose first language is not English; assesses receptive and productive skills at B1–B2 CEFR.

**Syllabus code:** `0510`  
**Age range:** 14–16  
**Prerequisites:** Working knowledge of English (typically CEFR A2+).
